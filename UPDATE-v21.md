# MSPgram v21 «Fixed» — как обновиться (2 минуты)

**Миграция базы данных НЕ нужна.**

## 1. Закоммитить файлы
Распакуй `MSPgram-v21-update.zip` **поверх** папки репозитория (с заменой файлов), затем в терминале:

```bash
git add -A
git commit -m "MSPgram v21: фиксация экрана, рингтоны звонка, уведомления на Android, кнопка кружков"
git push
```
GitHub Desktop: слева появятся изменённые файлы → Summary → **Commit to main** → **Push origin**.
Через сайт GitHub: Add file → Upload files → перетащи содержимое архива (папки `css`, `js` и файлы) → Commit changes.

GitHub Pages обновится через 1–2 минуты. В приложении (APK) закрой его полностью и открой снова —
service worker сам подтянет v21 (в Админ-панели → Система есть «Сбросить кэш»).

## 2. Что исправлено

### 📱 Приложение больше не «растягивается как на ПК»
* viewport жёстко зафиксирован (без зума щипком и двойным тапом, `maximum-scale=1`).
* `html/body` «прибиты» к экрану: нет «резинки» при оттягивании, нет горизонтальной прокрутки.
* Высота интерфейса следует за **видимой областью** (`visualViewport`): когда открывается клавиатура, поле ввода
  остаётся над ней, а шапка не уезжает.
* Safe-area: шапка и нижние панели не залезают под вырез/жесты.
* Поля ввода 16px — iOS не приближает страницу при фокусе.
* Телефон в альбомной ориентации тоже получает мобильный интерфейс (а не «ПК-вёрстку»).
* Кнопка **«Назад»** на Android закрывает окно/чат, а не выкидывает из приложения.
* В `manifest.webmanifest` добавлено `"orientation": "portrait"` (если нужна альбомная — удали эту строку).

### ⭕ Видеокружки на телефоне
Кнопка кружка была скрыта в CSS на экранах уже 420px (`#video-btn { display:none }`) — поэтому «кружков нет».
Теперь ряд иконок (скрепка, стикеры, GIF, ИИ, 🎤, ⭕) на телефоне вынесен отдельной строкой над полем текста —
все кнопки помещаются.

### 🔔 Уведомления
* Причина, почему в APK их не было: `new Notification()` **не работает на Android**. Теперь уведомления показываются
  через Service Worker (`registration.showNotification`) — это работает в Chrome/TWA/APK.
* Клик по уведомлению открывает приложение и нужный чат.
* Разрешение запрашивается при первом касании; в Настройках → Уведомления есть кнопка «Включить»
  (после включения приходит тестовое уведомление).
* Колокольчик 🔔 в шапке (центр уведомлений) всегда виден и не сжимается.
* Всплывающие системные уведомления показываются, когда приложение свёрнуто/не в фокусе.

### 📞 Звуки звонка
* **Когда тебе звонят** — мелодия-рингтон по кругу + вибрация + анимированная кнопка «принять».
  Если приложение свёрнуто — приходит системное уведомление «Имя звонит».
* **Когда ты звонишь** — длинные гудки «ту-у…», замолкают, когда собеседник ответил.
* Файлов не нужно: звук генерируется кодом (`js/ringtone.js`).
* Настройки → Уведомления → «Рингтон звонка»: включить/выключить и ▶ прослушать.
* Статус «Не беспокоить» глушит рингтон.

## 3. Честно об ограничениях
* Браузеры разрешают звук только после первого касания экрана. Если приложение открыли и ни разу не коснулись —
  первый звонок может прозвучать как короткий сигнал. Обычно этого не случается: ты уже нажал на чат.
* Когда приложение **полностью закрыто / убито системой**, ни звонок, ни уведомление прийти не могут: для этого нужен
  настоящий Web Push (серверная часть: Supabase Edge Function + VAPID-ключи). В `service-worker.js` уже добавлен
  обработчик `push` — клиентская часть готова. Пока работает: приложение открыто или свёрнуто.
