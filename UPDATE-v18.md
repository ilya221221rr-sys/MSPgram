# MSPgram v18 «Aurora» — как обновиться (5 минут)

## 1. Закоммитить файлы
Распакуй архив **поверх** папки репозитория (с заменой файлов) и:

```bash
git add -A
git commit -m "MSPgram v18 Aurora"
git push
```
GitHub Pages сам обновит сайт через 1–2 минуты. Service worker подхватит новую версию автоматически.

## 2. Применить миграцию БД (обязательно, один раз)
Supabase → **SQL Editor → New query** → вставить весь файл `supabase/migration-9-v18.sql` → **Run**.
Можно запускать повторно — данные не пострадают. ⚠️ Файл `schema.sql` повторно НЕ запускать (он стирает таблицы).

Без миграции приложение работает, но не будут работать: друзья, статусы присутствия, приватность,
активные сессии, права групп, «доставлено», роль модератора, 🔒 защита от самоповышения до админа.

## 3. По желанию
* **2FA** — Supabase → Authentication → Sign In / Providers → Multi-Factor → включить TOTP (обычно включено по умолчанию).
* **GIF** — бесплатный ключ на developers.giphy.com; вписать в `js/config.js` (`giphyKey`) или в панель GIF.
* **Почта** — регистрация по email, подтверждение письмом работает как раньше (Authentication → Email → Confirm email = ON).
* **ИИ** — работает сразу (бесплатный шлюз Pollinations). Свой сервис: Настройки → ИИ и GIF.

## Что исправлено (баги прошлой версии)
| Проблема | Причина | Решение |
|---|---|---|
| В списке чатов «Чат» без имени и аватарки | запрос возвращал `chat_members`, а код читал `chat.members` | алиас `members:chat_members(...)` в `api.js` + страховка в `api-v18.js` |
| Сообщения не приходили в реальном времени | `presence.js` вызывал несуществующий `dbApi.touchLastSeen()` → ошибка до запуска realtime | функция добавлена, запуск presence обёрнут в try/catch |
| Любой мог сделать себя админом (`is_admin = true`) | не было защитного триггера | триггеры `guard_profile_update` / `guard_member_update` |
| В админке вкладка чатов падала | `chat.members` vs `chat_members` | исправлено |

## Что нового
**Общение:** статусы ✓ отправлено / ✓✓ доставлено / ✓✓ прочитано, упоминания @ник (подсветка + уведомление),
уведомления о реакциях, GIF (Giphy), права групп (режим канала «пишут только админы», запрет медиа, роли админов),
описание сообщества, перевод сообщения, ответ от ИИ.
**Профили:** друзья (заявки, принятие, список), приватность (кто видит «был в сети», кто может писать, кто видит «О себе»),
эмодзи-статус, статусы «в сети / отошёл / не беспокоить / невидимка» (+ автоотход через 5 минут), «О себе» в профиле.
**Поиск:** по людям, чатам, **сообщениям всех чатов** и **публичным сообществам** (с кнопкой «Вступить»), история запросов.
**ИИ:** MSP AI (диалог внутри приложения), помощь в тексте (исправить / улучшить / короче / дружелюбнее / официальнее / перевести),
умные варианты ответа, краткий пересказ переписки, перевод на 15 языков.
**Дизайн:** SVG-иконки, нижняя навигация, фильтры чатов (все / непрочитанные / личные / группы), новые строки чатов
(аватар, имя, @ник, статус, счётчик), анимации, центр уведомлений, умные плашки, тема «как в системе», любой цвет акцента, 5 мелодий + громкость.
**Безопасность:** 2FA (TOTP), смена пароля, активные сессии (список устройств, завершение по одному и всех остальных).
**Админка:** роли (пользователь / модератор / админ), вкладка «Сообщества» (скрыть/удалить), модератор видит жалобы и может банить.
**Звонки:** групповой видеозвонок (сетка видео, камера и микрофон вкл/выкл) в дополнение к 1-на-1 и голосовым каналам.

## Честно о границах
* «Кто видит „был в сети“ / „О себе“» скрывается в интерфейсе; запрет писать (`privacy_messages`) и права групп проверяет **сервер** (RLS).
* 2FA блокирует вход в приложение до ввода кода. Данные защищены также паролем и RLS.
* Групповые звонки — P2P (mesh): комфортно до ~5–6 человек.
