# 🚀 Запуск MSPgram с нуля — пошагово (15 минут, 0 ₽)

Всё делается в браузере, без установки программ, без карты и без VPN.

---

## Шаг 1. Создай проект на Supabase (~5 минут)

1. Открой **https://supabase.com** → кнопка **Start your project** →
   **Sign up** (можно через GitHub-аккаунт или email).
2. Нажми **New project** (или **Create organization** → имя любое → **New project**).
3. Заполни:
   - **Name:** `mspgram`
   - **Database Password:** придумай и **сохрани** (понадобится редко, но пусть будет)
   - **Region:** выбери `West EU (Ireland)` — поближе к России и быстрее пинг
4. Нажми **Create new project** и подожди ~2 минуты, пока проект создаётся.
5. Настрой адрес приложения — чтобы ссылки из писем (подтверждение почты и
   восстановление пароля) возвращали на сайт, а не на технический адрес:
   слева **Authentication** → **URL Configuration**:
   - **Site URL:** `https://ilya221221rr-sys.github.io/MSPgram`
   - **Redirect URLs** → **Add URL** → `https://ilya221221rr-sys.github.io/MSPgram/**`
6. Проверь, что подтверждение почты включено (оно включено по умолчанию):
   **Authentication** → **Sign In / Providers** → **Email** → тумблер
   **Confirm email** включён.

> ⚠️ После создания проект «спит» после 7 дней полного бездействия.
> Если мессенджером пользоваться хотя бы раз в неделю — он не заснёт никогда.
> Заснул — зайди в панель и нажми **Restore project** (данные не пропадают).

---

## Шаг 2. Создай базу данных (~2 минуты)

1. В панели проекта слева открой **SQL Editor** (иконка `>_`).
2. Нажми **New query**.
3. Открой файл [`supabase/schema.sql`](supabase/schema.sql) в этом репозитории,
   выдели всё (Ctrl+A), скопируй и вставь в поле запроса.
4. Нажми **Run** (или Ctrl+Enter).
5. Внизу должно появиться `Success. No rows returned` — это успех. ✅

Проверка: слева открой **Table Editor** — там должны появиться таблицы
`profiles`, `chats`, `chat_members`, `messages`.

---

## Шаг 3. Вставь ключи в приложение (~1 минута)

1. В панели Supabase открой **⚙️ Project Settings → API** (или **Data API**).
2. Скопируй две строки:
   - **Project URL** — вида `https://abcdefghijk.supabase.co`
   - **anon public** — длинная строка-ключ (это НЕ секретный ключ, его можно коммитить)
3. Открой в репозитории файл **`js/config.js`** и замени:

```js
window.MSP_CONFIG = {
  supabaseUrl: "https://abcdefghijk.supabase.co",   // ← твой Project URL
  supabaseAnonKey: "eyJhbGciOi...длинная_строка",   // ← твой anon public
};
```

4. Сделай **Commit** изменений (в интерфейсе GitHub: карандашик →
   `Commit changes`, у себя на компьютере: `git add -A && git commit && git push`).

> 💡 Если ключи не вписать — приложение при первом открытии само покажет
> экран настройки и попросит их вставить (они сохранятся в браузере).

---

## Шаг 4. Включи GitHub Pages (~2 минуты)

1. Зайди в свой репозиторий на GitHub → **Settings** → **Pages**
   (слева, раздел «Code and automation»).
2. В блоке **Build and deployment**:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`, папка `/ (root)` → **Save**
3. Подожди 1–2 минуты и обнови страницу — сверху появится зелёная плашка:
   `Your site is live at https://ТВОЙ_НИК.github.io/MSPgram/`

Готово! 🎉 Открой этот адрес с телефона и компьютера — можно переписываться.

---

## Шаг 5. Установи как приложение на телефон (по желанию)

**Android (Chrome):** открой сайт → меню ⋮ → **«Добавить на главный экран»**.
Появится иконка MSPgram как у обычного приложения, на весь экран.

**iPhone (Safari):** кнопка «Поделиться» → **«На экран “Домой”»**.

**Компьютер:** в адресной строке справа появится значок «Установить».

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| «Failed to fetch» при входе | Неправильный URL проекта — проверь Шаг 3 |
| `relation "profiles" does not exist` | Не выполнен SQL из Шага 2 |
| Письмо с подтверждением не приходит | На бесплатном плане письма приходят с общего адреса, проверь «Спам». Или отключи: **Authentication → Providers → Email → Confirm email** (выключить тумблер) |
| Сайт 404 после включения Pages | Подожди пару минут, обнови; проверь, что ветка `main` |
| Иконка не ставится на телефон | Адрес должен быть `https://...github.io/...` (не IP, не http) |
| Сообщения приходят с задержкой | Обнови страницу; проверь интернет. Realtime должен быть включён по умолчанию |

## Как зарегистрировать друзей

Скинь им адрес сайта. Каждый регистрируется сам (Шаг «Регистрация» на
экране входа), потом вы находите друг друга по нику через поиск.

## Хочешь свой домен (например `mspgram.ru`)?

Это единственная необязательная трата (~200–800 ₽/год за домен).
Настройка: Settings → Pages → Custom domain. Без домена всё работает бесплатно.
