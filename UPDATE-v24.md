# MSPgram v24 «Auto Push» — сообщения при полностью закрытом приложении

**Почему раньше не приходило.** Сообщения при закрытом приложении доставляет только серверный Web Push.
Код приложения для него есть с v22, но серверная часть (Edge Function `send-push`) на Supabase
**не была развёрнута** (проверка: адрес функции отвечал `404 NOT_FOUND`). v24 включает её за один клик.

## 1. Залить файлы (2 минуты)
Распакуй `MSPgram-v24-update.zip` **поверх** папки репозитория (с заменой; `js/config.js` в архиве нет).
В архиве есть скрытая папка `.github` — убедись, что она тоже попала в коммит:

```bash
git add -A
git commit -m "MSPgram v24: включение push в один клик"
git push
```
Через сайт GitHub: Add file → Upload files → перетащи содержимое архива (вместе с папкой `.github`) → Commit changes.
Если папка `.github` не загрузилась: Add file → Create new file → имя `.github/workflows/setup-push.yml` → вставь содержимое файла из архива.

## 2. Токен Supabase → секрет GitHub (3 минуты, один раз)
1. https://supabase.com/dashboard/account/tokens → **Generate new token** → скопируй.
2. Репозиторий на GitHub → **Settings → Secrets and variables → Actions → New repository secret**
   Имя: `SUPABASE_ACCESS_TOKEN`, значение: токен → Add secret.

## 3. Запустить настройку (1 минута)
GitHub → вкладка **Actions** → слева **«Включить push на сервере»** → **Run workflow** → Run.
Подожди ~1 минуту: должна появиться зелёная галочка. Скрипт сам:
* создаёт ключи VAPID и секрет вебхука и кладёт их в Supabase Secrets;
* разворачивает функцию `send-push` (без Verify JWT);
* применяет `migration-11-webpush.sql` и `migration-12-v23.sql`, записывает `function_url` и `webhook_secret`;
* проверяет, что функция отвечает и ключи заданы.

Ручной ввод ключей и SQL больше не нужен. Запускать можно повторно в любое время (ключи VAPID не меняются,
пока не поставишь галочку «Пересоздать»). Токен потом можно удалить в Supabase.

## 4. Включить push на каждом телефоне (обязательно!)
Подписка создаётся на каждом устройстве отдельно:
1. Открой приложение (после обновления закрой полностью и открой снова — появится **v24** в шапке).
2. **Настройки → Push-уведомления → Включить**, разреши уведомления.
3. **Настройки → Диагностика push** — все пункты должны быть ✅. Нажми «Тест с сервера», закрой приложение — придёт уведомление.

Друзьям нужно сделать то же самое на своих телефонах (один раз).

## 5. Важно про Android-приложение (APK)
* Если APK — «голый» WebView, Web Push в нём не работает **вообще** (ограничение Android). Диагностика покажет красный пункт «Оболочка приложения».
  Решение: собрать APK заново через **PWABuilder** (pwabuilder.com → адрес сайта → Android) — это TWA на базе Chrome, push работает.
  Или поставить сайт из Chrome: меню → «Установить приложение».
* Отключи для Chrome/приложения «Экономию заряда» и ограничения фоновой работы.
* iPhone: сайт должен быть добавлен «На экран Домой» (iOS 16.4+).
* Если приложение принудительно «остановлено» в настройках Android, push придёт только после следующего запуска.
