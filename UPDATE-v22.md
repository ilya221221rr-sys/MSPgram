# MSPgram v22 «Push» — как обновиться

Что нового:
* 🔔 **Настоящий Web Push** — сообщения и звонки приходят, даже когда приложение закрыто (серверная часть — Supabase Edge Function `send-push`).
* ◧ **Кнопка скрытия левой панели серверов** (самая левая в шапке списка чатов). Выбор запоминается. Если в скрытой панели есть непрочитанный сервер — на кнопке горит красная точка.
* 🔊 Звук разблокируется первым касанием надёжнее (Chrome на Android не считал `pointerdown` жестом — из-за этого рингтон иногда молчал).
* Тап по уведомлению открывает нужный чат, даже если приложение было полностью закрыто.

## 1. Закоммитить файлы (2 минуты)
Распакуй `MSPgram-v22-update.zip` **поверх** папки репозитория (с заменой файлов; `js/config.js` в архиве нет — твои ключи не затрутся):

```bash
git add -A
git commit -m "MSPgram v22: Web Push (Supabase Edge Function), скрытие панели серверов"
git push
```
Через сайт GitHub: Add file → Upload files → перетащи содержимое архива → Commit changes.
GitHub Pages обновится через 1–2 минуты. В приложении закрой его полностью и открой снова.

## 2. Включить серверный push (один раз, ~10 минут)

### 2.1 Ключи VAPID и секрет
Открой страницу-помощник (она лежит рядом с архивом обновления) — она создаёт ключи прямо в твоём браузере и показывает готовые значения.
Либо в терминале: `npx web-push generate-vapid-keys`.

### 2.2 База данных
Supabase → **SQL Editor** → вставь весь `supabase/migration-11-webpush.sql` → Run.
Затем выполни запрос с адресом функции и секретом (его показывает страница-помощник):

```sql
insert into public.push_settings (key, value) values
  ('function_url',  'https://xqjtycvfjamnqtkznyio.supabase.co/functions/v1/send-push'),
  ('webhook_secret', 'ТВОЙ_СЕКРЕТ')
on conflict (key) do update set value = excluded.value;
```

### 2.3 Секреты функции
Supabase → **Edge Functions → Secrets** (или `supabase secrets set ...`), добавь 4 значения:

| Имя | Значение |
|---|---|
| `VAPID_PUBLIC_KEY` | публичный ключ |
| `VAPID_PRIVATE_KEY` | приватный ключ (**никому не показывать, в репозиторий не коммитить**) |
| `VAPID_SUBJECT` | `mailto:твоя@почта.ru` |
| `PUSH_WEBHOOK_SECRET` | тот же секрет, что в SQL выше |

### 2.4 Деплой функции
**Через панель:** Edge Functions → Deploy a new function → имя `send-push` → вставь код из `supabase/functions/send-push/index.ts` → Deploy → в настройках функции **выключи «Verify JWT»**.

**Через CLI:**
```bash
supabase login
supabase link --project-ref xqjtycvfjamnqtkznyio
supabase functions deploy send-push --no-verify-jwt
```
(Проверка пользователя выполняется внутри функции, поэтому JWT на входе отключён: иначе триггер БД не сможет её вызвать.)

### 2.5 Включить на телефоне
Приложение → Настройки → **Push-уведомления** → «Включить» (разреши уведомления) → придёт тестовый push «с сервера».
Каждый пользователь делает это один раз на своём устройстве (после входа подписка обновляется сама).

## 3. Как это работает
* `js/webpush.js` подписывает устройство (`PushManager.subscribe`) и сохраняет подписку в таблицу `push_subscriptions` (RPC `register_push`).
  Публичный ключ приложение берёт у самой функции — в `config.js` ничего вписывать не надо.
* Новое сообщение → триггер БД `trg_push_on_message` → Edge Function → push всем участникам чата, **кроме отправителя, тех, кто заглушил чат, и тех, кто заблокировал отправителя**. Из записей о звонках пушатся только «пропущенный/отменённый».
* Исходящий звонок → приложение вызывает функцию → собеседнику приходит «📞 Имя звонит» (живёт 45 секунд).
* При выходе из аккаунта устройство отвязывается — чужие сообщения на него приходить не будут.
* Мёртвые подписки (404/410) функция удаляет сама.
* Если приложение открыто и на экране — push не показывается (чтобы не было дублей): работает обычная плашка внутри приложения.

## 4. Честно об ограничениях
* **Звук:** браузеры разрешают звук только после первого касания экрана. v22 ловит это касание и «будит» звук. Но когда приложение убито, push приходит со **звуком и вибрацией самого уведомления**, а не рингтоном — рингтон (`ringtone.js`) играет только в запущенном приложении. Тап по уведомлению открывает чат.
* **APK:** Web Push работает, если APK — это TWA / PWABuilder / Bubblewrap (использует Chrome). В «голом» WebView-приложении Web Push не поддерживается Android вообще — тогда ставь PWA через Chrome («Установить приложение»).
* **iPhone:** push работает только если сайт добавлен «На экран Домой» (iOS 16.4+).
* Если пользователь принудительно «остановил» приложение в настройках Android, система не доставляет push до следующего запуска.
* Звонок при закрытом приложении: уведомление придёт, но соединение устанавливается только после открытия приложения — звонящий ждёт до 40 секунд, потом звонок станет «пропущенным».
