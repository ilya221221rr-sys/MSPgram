# MSPgram v20 «Aurora» — как обновиться (3 минуты)

**Миграция базы данных НЕ нужна.** Все новые функции работают на уже существующих таблицах.

## 1. Закоммитить файлы
Распакуй архив `MSPgram-v20-update.zip` **поверх** папки репозитория (с заменой файлов), затем в терминале внутри папки проекта:

```bash
git status                      # посмотреть, что изменилось
git add -A
git commit -m "MSPgram v20 Aurora: фото в ИИ, видеокружки, камера в звонке, история звонков, новая панель"
git push
```
Либо без распаковки — одной командой через патч (из папки репозитория):
```bash
git apply MSPgram-v20.patch && git add -A && git commit -m "MSPgram v20 Aurora" && git push
```
GitHub Pages обновит сайт через 1–2 минуты. Service worker подхватит новую версию сам
(если интерфейс старый — Ctrl+F5, или Админ-панель → ⚙ Система → «Сбросить кэш»).

> GitHub Desktop: открой репозиторий → слева появятся изменённые файлы → Summary: `MSPgram v20 Aurora` → **Commit to main** → **Push origin**.
> Через сайт GitHub: Add file → Upload files → перетащи содержимое архива → Commit changes.

**Если что-то пошло не так:** `git revert HEAD && git push` вернёт предыдущую версию.

## 2. Что нового

### 🖼 Фото в ИИ
* В окне **MSP AI** слева от поля ввода — кнопка 🖼: выбери фото, **перетащи** его в окно или **вставь из буфера** (Ctrl+V).
* Фото сжимается в браузере (до 1280 px) и уходит только в ИИ — на твой Supabase не загружается.
* Быстрые кнопки: «Опиши фото», «Текст с фото», «Реши задачу».
* В любом чате: меню сообщения (⋯) у фото → **«✨ Спросить ИИ о фото»**.
* ⚠️ **Нужен бесплатный ключ OpenRouter (один раз).** Анонимный Pollinations картинки не понимает (проверено — отвечает
  «This model does not support image input»). При первой отправке фото MSPgram сам покажет карточку: получи ключ на
  https://openrouter.ai/keys (вход через Google/GitHub, карта не нужна), вставь `sk-or-v1-…` — и всё работает.
  Остальные функции ИИ (перевод, пересказ, умные ответы) этот ключ не затрагивает. Если у тебя в Настройках → ИИ уже стоит
  OpenRouter-ключ — он используется автоматически. Если стоит свой провайдер (OpenAI-совместимый) — фото уйдёт ему.
* Модели подбираются сами: `openrouter/free` → свежие бесплатные модели «с глазами» из каталога OpenRouter.

### 🎛 Нижняя панель
Стеклянный «плавающий» док: подсвечивается открытый раздел, **MSP AI** выделен как главная кнопка,
вместо «Настроек» — **Профиль** с твоей аватаркой и статусом (открывает профиль и настройки).

### 📹 Камера во время обычного звонка
В аудиозвонке появилась кнопка камеры: включил — собеседник сразу видит видео, выключил — снова только голос.
Соединение при этом **не пересоздаётся** (видео-«слот» создаётся заранее), поэтому нет пауз и обрывов.
Кнопка 🔄 — перевернуть камеру (на телефоне). Мягкие настройки видео (≈640×360, до 24 к/с, до 0.8 Мбит/с,
приоритет плавности) — чтобы не лагало.

### ⭕ Видеокружки как в Telegram
Кнопка камеры в поле ввода записывает **кружок**: круглое превью, кольцо-таймер до 60 сек, переворот камеры.
Запись лёгкая (480×480, 24 к/с, ~0.6 Мбит/с, кодек VP8 / H.264 на Safari) — не греет и не лагает.
В чате кружок воспроизводится по тапу, с кольцом прогресса. Обычное видео по-прежнему можно прикрепить скрепкой.

### 📞 Звонок не сбрасывается, если выйти из приложения
* **Свернуть** (кнопка в углу звонка): звонок превращается в плашку сверху, а ты листаешь чаты. Клик по плашке — развернуть.
* Видео собеседника при выходе из вкладки/приложения уходит в **окно «картинка в картинке»** (кнопка PiP).
* Экран не засыпает во время звонка (Wake Lock), в шторке уведомлений/на экране блокировки появляется «Звонок · Имя»
  с кнопкой «Завершить» (Media Session).
* **Авто-восстановление связи**: при смене сети (Wi‑Fi ↔ LTE) или возврате в приложение звонок переподключается сам
  (ICE restart), а не сбрасывается. Раньше принимающая сторона вылетала при любом коротком «disconnected».
* Если звонящий отменил вызов, у собеседника **сразу пропадает окно входящего** (раньше висело до 45 сек).

### 🕘 История звонков в чате
Каждый звонок появляется в переписке карточкой: «Исходящий звонок · 2:13», «Пропущенный видеозвонок»,
«Вы отклонили звонок», «Нет ответа», «Собеседник занят». Кнопка справа — **позвонить ещё раз**.
Звонок записывается как обычное сообщение, поэтому виден обоим, отображается в списке чатов,
даёт уведомление о пропущенном и попадает в поиск.

## 3. Честно об ограничениях веб-приложения
* **Android (Chrome/PWA):** звонок продолжается в фоне, микрофон остаётся включённым — работает хорошо.
* **iPhone (Safari/PWA):** iOS замораживает веб-приложения в фоне. PiP, Wake Lock и авто-восстановление помогают, но
  Apple не гарантирует работу звука при свёрнутом PWA. Это ограничение системы, а не MSPgram.
* **Входящий звонок при закрытом приложении** принять нельзя — для этого нужны Web Push + сервер/Edge Function. Пропущенный звонок
  при этом останется в истории чата, и собеседник увидит уведомление о нём.
