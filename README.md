## Как запустить (15 минут, бесплатно)

Открой **[SETUP.md](SETUP.md)** и делай шаг за шагом:

1. Создать проект на Supabase (~5 минут, без карты)
2. Выполнить SQL из `supabase/schema.sql` (~2 минуты)
3. Вставить 2 ключа в `js/config.js` (~1 минута)
4. Включить GitHub Pages (~2 минуты)

Всё. Дальше приложение доступно по адресу
`https://ТВОЙ_НИК.github.io/MSPgram/` — и тебе, и всем, кому скинешь ссылку.

## Структура проекта

```
index.html            — одна страница приложения
css/style.css         — стили (тёмная тема)
js/config.js          — 👉 сюда вставляются ключи Supabase
js/app.js             — точка входа: запуск, realtime, уведомления
js/api.js             — работа с Supabase (база, файлы, состояние)
js/auth.js            — вход и регистрация
js/chatlist.js        — список чатов, поиск людей, создание групп
js/chatview.js        — окно чата: сообщения, вложения, «печатает…»
js/presence.js        — онлайн-статусы
js/utils.js           — вспомогательные функции
js/vendor/supabase.js — библиотека Supabase (лежит в репо, CDN не нужен)
supabase/schema.sql   — 👉 SQL-схема: вставить в Supabase SQL Editor
service-worker.js     — офлайн-кэш (PWA)
manifest.webmanifest  — манифест PWA (иконки, название)
icons/                — иконки приложения
```

## Безопасность

- В коде страниц нет секретных ключей — только публичный `anon`-ключ,
  он для этого и предназначен.
- Все данные защищены правилами RLS (Row Level Security) на сервере:
  чужие чаты и сообщения прочитать/изменить нельзя, даже подделав запрос.
- Пароли хранит Supabase (bcrypt), код их не видит.

## Категория «данные и лимиты» (бесплатный план Supabase)

- База 500 МБ, файлы 1 ГБ, трафик 5 ГБ/мес — этого хватает на годы
  переписки небольшой компании.
- Если проектом не пользоваться **7 дней подряд**, Supabase его «усыпит» —
  данные не пропадут, надо нажать Restore в панели. Активные чаты не дают
  проекту уснуть.
