# MSPgram для Android — нативное приложение (настройка за 15 минут)

Это **настоящее нативное приложение** (Kotlin + Jetpack Compose), а не обёртка.
Оно подключается к той же базе, что и сайт: те же чаты, та же переписка.
Главное отличие — **push-уведомления работают при полностью закрытом приложении** (через Google FCM).

## Что нужно (всё бесплатно)
- аккаунт Google (есть у всех)
- 15 минут времени

## Шаг 1. Firebase-проект для push (5 минут)
1. Открой **console.firebase.google.com** → **Создать проект** → имя `MSPgram` → аналитику можно выключить → Создать
2. В проекте: шестерёнка **⚙️ Настройки проекта** → вкладка **Общие**
3. Нажми **«Приложение Android»** (иконка робота):
   - Имя пакета: `com.mspgram.app`
   - Название: `MSPgram`
   - Нажми **Зарегистрировать приложение** (файл google-services.json можно НЕ скачивать)
4. На вкладке **Общие** найди карточку приложения `com.mspgram.app` и выпиши 4 значения:
   - `application_id` (вида `1:1234567890:android:abc123...`)
   - `API-ключ` (вида `AIzaSy...`)
   - `Идентификатор проекта` (вида `mspgram-xxxxx`)
   - `Номер отправителя` (вида `1234567890`)
5. Вкладка **Настройки проекта → Сервисные аккаунты** → **Создать новый закрытый ключ** → скачается JSON-файл → **сохрани его, он понадобится в шаге 3**

## Шаг 2. Вписать 4 значения в приложение
1. Открой в проекте файл `android/app/src/main/assets/firebase-config.json`
2. Замени все `PLACEHOLDER` на свои значения из шага 1:
   ```json
   {
     "applicationId": "1:1234567890:android:abc123",
     "apiKey": "AIzaSy...",
     "projectId": "mspgram-xxxxx",
     "senderId": "1234567890"
   }
   ```
3. Напиши мне «вписал» — я закоммичу изменения

## Шаг 3. Включить push-сервер (2 минуты)
1. Открой GitHub → репозиторий MSPgram → **Settings → Secrets and variables → Actions**
2. **New repository secret**:
   - Имя: `FCM_SERVICE_ACCOUNT_JSON`
   - Значение: открой JSON-файл из шага 1.5 и скопируй **весь текст целиком**
3. Вкладка **Actions** → слева **«Включить FCM push для Android»** → **Run workflow** → подожди зелёную галочку

## Шаг 4. Собрать APK (5 минут)
1. Вкладка **Actions** → **«Собрать Android-приложение»** → **Run workflow**
2. Через 5–8 минут нажми на завершённый запуск → внизу раздел **Artifacts** → скачай **MSPgram-APK**
3. Распакуй zip на телефоне → открой `app-debug.apk` → разреши установку из этого источника → **Установить**

## Шаг 5. Проверка push
1. Открой приложение → войди тем же аккаунтом, что на сайте
2. Разреши уведомления (система спросит)
3. Закрой приложение **полностью**
4. Отправь себе сообщение с сайта (или попроси друга)
5. 🔔 Уведомление приходит при закрытом приложении — готово!

## Важно знать
- **Push работает** на телефонах с Google-сервисами (Samsung, Xiaomi, Pixel и почти все). На Huawei без Google — нет
- Приложение = все функции сайта (v26): чаты, звонки, кружки, стикеры, реакции, ИИ, серверы, админка — и push при закрытом приложении
- APK подписан debug-ключом — для себя и друзей это нормально. Для Google Play нужна release-подписка (скажи, если решишь выкладывать)
- Обновления сайта мгновенно попадают и в приложение (оно читает ту же базу), **но** новые функции интерфейса нужно дорисовывать отдельно — я делаю это по твоим заказам

## Из чего состоит (для интересующихся)
```
android/                          — весь проект приложения (Kotlin + Jetpack Compose)
  app/src/main/java/.../Supa.kt   — клиент Supabase: REST, авторизация, Realtime
  app/src/main/java/.../MainActivity.kt — экраны: вход, чаты, переписка
  app/src/main/java/.../PushService.kt  — приём push при закрытом приложении
  app/src/main/assets/firebase-config.json — 4 значения из Firebase
supabase/migration-13-fcm.sql     — таблица токенов + триггер на сообщения
supabase/functions/send-fcm/      — сервер: рассылка push через Google FCM
.github/workflows/build-android.yml — автосборка APK
.github/workflows/setup-fcm.yml   — автонастройка push-сервера
```
