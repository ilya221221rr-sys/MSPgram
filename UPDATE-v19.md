# MSPgram v19 «Nova» — как обновиться (5 минут)

## 1. Закоммитить файлы
Распакуй архив **поверх** папки репозитория (с заменой файлов), затем в терминале внутри папки проекта:

```bash
git status                      # посмотреть, что изменилось
git add -A
git commit -m "MSPgram v19 Nova"
git push
```
GitHub Pages обновит сайт через 1–2 минуты. Service worker подхватит новую версию сам
(если интерфейс старый — нажми Ctrl+F5 или Админ-панель → ⚙ Система → «Сбросить кэш»).

> Через GitHub Desktop: открой репозиторий → слева появятся изменённые файлы → Summary: `MSPgram v19 Nova` →
> **Commit to main** → **Push origin**.
> Через сайт GitHub: Add file → Upload files → перетащи содержимое архива → Commit changes.

**Если что-то пошло не так:** `git revert HEAD && git push` вернёт предыдущую версию.

## 2. Применить миграцию БД (один раз)
Supabase → **SQL Editor → New query** → вставить весь файл `supabase/migration-10-v19.sql` → **Run**.
Можно запускать повторно. ⚠️ `schema.sql` повторно НЕ запускать.

Без миграции приложение работает, но не будут работать: рассылки, журнал действий, заметки о пользователях,
серверный журнал ошибок ИИ. Проверить можно в Админ-панель → ⚙ Система: там видно, каких таблиц не хватает.

## 3. Починить ИИ (OpenRouter Free → 404)
**Почему была ошибка 404.** Приложение отправляло запрос ровно на тот адрес, что вписан в настройках.
Если там `https://openrouter.ai/api/v1` (без `/chat/completions`) — OpenRouter отвечает `404 Not Found`.
Вторая частая причина — бесплатную модель (`…:free`) убрали из каталога («No endpoints found»),
третья — в настройках приватности OpenRouter выключены бесплатные эндпоинты.

**Что сделано в v19:**
* адрес OpenRouter исправляется автоматически (подойдёт любой вариант: `openrouter.ai`, `…/api/v1`, …);
* если модель не отвечает, MSPgram сам перебирает запасные: `openrouter/free` (авто-подбор живой бесплатной модели)
  и свежий список бесплатных моделей из каталога OpenRouter;
* для моделей, не принимающих системные инструкции (Gemma и др.), запрос повторяется без них;
* **полный журнал ошибок**: что отправили, что ответил сервер, и подсказка «что делать» по-русски.

**Как посмотреть, почему ИИ не работает:**
* Настройки → ИИ и GIF → **🩺 Диагностика** → «Запустить проверку» (проверит связь, ключ, модель и сделает тестовый запрос);
* Админ-панель → **🩺 ИИ** — то же + ошибки ИИ у всех пользователей (после миграции).

**Быстрая настройка:** Настройки → ИИ и GIF → кнопка **⚡ OpenRouter Free** → вставь ключ `sk-or-v1-…`
(бесплатный, https://openrouter.ai/keys) → Сохранить.
Если всё равно 404: открой https://openrouter.ai/settings/privacy и включи
**«Enable free endpoints that may train on inputs / publish prompts»**.

## Что нового в v19
**Дизайн:** новая тема Nova, 6 скинов (Nova, AMOLED, Midnight, Graphite, Plum, Forest), 8 обоев чата, 3 формы пузырей
(в т.ч. «как в Telegram»), компактный режим, режим «меньше анимаций», стеклянные шапки, плавные появления.
**Как в Telegram:** папки чатов со счётчиками, черновики (с пометкой «Черновик:» в списке), свайп влево — ответить,
форматирование `**жирный**` `__курсив__` `~~зачёркнутый~~` `||спойлер||` `` `код` `` и блоки кода, подсказки @упоминаний,
быстрый переход **Ctrl/⌘+K** (чаты и команды), Alt+↑/↓ — соседний чат, плашка «Нет соединения».
**Админка:** поиск, фильтры и сортировка пользователей, карточка пользователя (статистика, заметка, стереть сообщения),
диалог бана со сроками и причинами, экспорт в CSV, рассылки-объявления всем пользователям, журнал действий персонала,
вкладка «Система» (состояние БД, активность, отклик, сброс кэша), диагностика ИИ.
